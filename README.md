# Business Sales Performance Analytics Dashboard

## Project Overview
This project analyzes ecommerce sales data to identify revenue trends,
top-performing products, profitable categories, and regional performance.

The dashboard was created using Power BI and includes interactive filters
for detailed business analysis.

## Tools Used
- Power BI
- Excel

## KPIs Tracked
- Total Sales Amount
- Total Quantity Sold
- Total Profit
- Average Order Value (AOV)

## Dashboard Features
- Monthly profit trend analysis
- State-wise sales performance
- Product category analysis
- Payment mode analysis
- Customer contribution analysis
- Interactive filtering and drill-down analysis

## Key Business Insights
1. Maharashtra generated the highest overall sales revenue.
2. Clothing category contributed the highest sales quantity.
3. COD was the most preferred payment method among customers.
4. Profit declined significantly during July and December.
5. Printers were the most profitable sub-category.

## Business Recommendations
1. Increase marketing campaigns in high-performing states.
2. Focus inventory on profitable sub-categories like Printers.
3. Investigate causes of losses during low-profit months.
4. Encourage online payment methods using offers or discounts.
5. Expand high-performing product categories.

## Conclusion
This analysis helps businesses understand sales performance,
customer behavior, and profitability trends for better decision-making.
